# Panel Duwoh

Panel interno de Duwoh Developers: clientes, proyectos y tareas, con usuarios, roles y permisos por proyecto.

- Front: `panel.duwohdevelopers.com` (Vercel)
- API: `api.duwohdevelopers.com` (Railway + Postgres)

## Arranque rápido

```bash
cp .env.example .env   # completar valores
npm install
npm run dev
```

Más detalle en [CONTRIBUTING.md](CONTRIBUTING.md). Stack, comandos y reglas en [AGENTS.md](AGENTS.md).
