# legacy/

Copia de CodeDesk (React + Firebase) **solo como referencia visual** para la fase 0: tema, `shared/ui`, layout del Dashboard y Login, que se reescriben en TypeScript dentro de `apps/web`.

- No es un workspace: no se instala, no se compila, no se lintea y no se importa desde `apps/`.
- No se edita.
- Se elimina al cerrar la fase 0 (PR 7, `feat(web): secciones`), cuando ya no quede nada por portar. Así se cumple "ninguna dependencia ni llamada a Firebase".
